A* Pathfinding Algorithm

Built an interactive A* pathfinding visualizer with p5.js. Place the start and goal anywhere, draw walls or generate random walls and solvable mazes, then watch the search expand step by step. Once it finishes, any edit re-runs the search instantly, so the shortest path updates live. Uses an octile-distance heuristic and a binary-heap open set, with optional diagonal moves and adjustable speed.
